这是一份面向《School Days REMASTERED》（スクールデイズ 重制版）的全结局攻略。

网上能找到的 School Days 攻略，大多是针对 HQ 版或更早版本写的。笔者照着这些攻略玩重制版，始终打不出想要的路线。于是笔者逆向了游戏程序，取出了全部好感度数值和路线分歧条件，并用游戏原本的分歧代码逐条重放验证，在此基础上整理出这份完整的全结局攻略：22 个结局各自的选项路线、每个选项对世界和言叶好感的影响、每个分歧点的判定条件，以及一次打完全部结局的存档顺序。

如果发现错误，欢迎通过页面底部的 X 或 GitHub 联系笔者。

机制

  • 好感有三个：世界、言叶、乙女，开局都是 0。
  • 加分发生在选项导向的场景上：选了某项后进入的场景如果在好感表里，就加对应的分。所以「不选」也可能加分。
  • 阈值判定都是严格大于。
  • 乙女好感只在 04-SE 和 05-5O 两段里能加。
