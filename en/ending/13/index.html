This is a complete walkthrough of every ending in School Days REMASTERED.

Most School Days guides online were written for the HQ edition or older releases. Following them in the remaster, I could never get the routes I wanted. So I reverse-engineered the game itself, pulled out every affection value and every branch condition, and replayed each route through the game's own branching code to check it. This guide is built on that: the choices for all 22 endings, how each choice changes Sekai's and Kotonoha's affection, the condition at every branch, and a save order for collecting every ending in one sitting.

If you find a mistake, contact me on X or GitHub at the bottom of the page.

No.13After the Kiss

キスから先へ · 42 choices, 5 key choices · Final episode: Sekai ≤ Kotonoha, then 「いいよ」

Key points

  • Route: Episode 1 “Confession” → Episode 2 “The Distance Between Us” → Episode 3 “Conflicting Desires” → Episode 4 “The Festival” → Episode 5 “Kotonoha Abandoned” → “After the Kiss”
  • Episode 2 “The Distance Between Us”
    To enter Episode 2 “The Distance Between Us”01-1K: Need Sekai ≤ Kotonoha (at this point Kotonoha 29 : Sekai 11); otherwise you enter Episode 2 “True Feelings”01-1S
  • Episode 3 “Conflicting Desires”
    To get the options “やっぱ、マズいって”（No, this is a bad idea）: Need Sekai ≤ Kotonoha (at this point Kotonoha 29 : Sekai 19); otherwise you get the options “じゃあ…”（Well then…） / “やっぱ、マズいって”（No, this is a bad idea）
  • Episode 4 “The Festival”
    Key picks: “待てよ” (Wait)
    plus 1 affection-building pick (Sekai+11)
  • Episode 5 “Kotonoha Abandoned”
    To enter Episode 5 “Mind and Body”04-C1: Need Sekai ≤ Kotonoha (at this point Kotonoha 56 : Sekai 30); otherwise you enter Final Episode No.14 Lust / No.15 Bavarian Cream05-SG
    Key picks: don't choose, “拒む” (Refuse)
  • Final Episode “After the Kiss”
    To get the options “いいよ”（Sure）: Need Sekai ≤ Kotonoha (at this point Kotonoha 87 : Sekai 46); otherwise you enter Final Episode No.8 Bloody End05-B0
    Key picks: “いいよ” (Sure) → ending
  • Finally: Final episode: Sekai ≤ Kotonoha, then 「いいよ」
