This is a complete walkthrough of every ending in School Days REMASTERED.

Most School Days guides online were written for the HQ edition or older releases. Following them in the remaster, I could never get the routes I wanted. So I reverse-engineered the game itself, pulled out every affection value and every branch condition, and replayed each route through the game's own branching code to check it. This guide is built on that: the choices for all 22 endings, how each choice changes Sekai's and Kotonoha's affection, the condition at every branch, and a save order for collecting every ending in one sitting.

If you find a mistake, contact me on X or GitHub at the bottom of the page.

Key points

  • Route: Episode 1 “Confession” → Episode 2 “True Feelings” → Episode 3 “Innocence” → Episode 4 “Setsuna” → Episode 5 “Secret Kiss” → “Bavarian Cream”

  • Episode 2 “True Feelings”
    To enter Episode 2 “True Feelings”01-1S: Need Sekai > Kotonoha (at this point Kotonoha 9 : Sekai 11); otherwise you enter Episode 2 “The Distance Between Us”01-1K
    Key picks: don't choose, don't choose
    plus 3 affection-building picks (Sekai+6)
  • Episode 3 “Innocence”
    To enter Episode 4 “A Real Couple” / “Setsuna”03-KA: Need Sekai ≤ Kotonoha (at this point Kotonoha 25 : Sekai 19); otherwise you enter Episode 4 “I'm Sorry” / “Kotonoha Broken” / “No More Hesitation”…03-SA
    Key picks: don't choose
    plus 2 affection-building picks (Kotonoha+16)
  • Episode 4 “Setsuna”
    To enter Episode 4 “Setsuna”03-AS: Need Sekai > Kotonoha (at this point Kotonoha 93 : Sekai 99); otherwise you enter Episode 4 “A Real Couple”03-AK
    Key picks: “打ち合わせる” (Meet to plan), “委員会が” (The committee…)
    plus 3 affection-building picks (Sekai+24)
  • Finally: Let one choice in Setsuna's episode 4 time out; added when you get No.14 or No.15
