This is a complete walkthrough of every ending in School Days REMASTERED.

Most School Days guides online were written for the HQ edition or older releases. Following them in the remaster, I could never get the routes I wanted. So I reverse-engineered the game itself, pulled out every affection value and every branch condition, and replayed each route through the game's own branching code to check it. This guide is built on that: the choices for all 22 endings, how each choice changes Sekai's and Kotonoha's affection, the condition at every branch, and a save order for collecting every ending in one sitting.

If you find a mistake, contact me on X or GitHub at the bottom of the page.

No.20Setsuna's Feelings

刹那の想い · 32 choices, 2 key choices · Final episode: Sekai > 46 and don't pick 「いられるよ」

Key points

  • Route: Episode 1 “Confession” → Episode 2 “True Feelings” → Episode 3 “Relationships Revealed” → Episode 4 “No More Hesitation” → Episode 5 “Transfer” → “Setsuna's Feelings”
  • Episode 2 “True Feelings”
    To enter Episode 2 “True Feelings”01-1S: Need Sekai > Kotonoha (at this point Kotonoha 5 : Sekai 18); otherwise you enter Episode 2 “The Distance Between Us”01-1K
    Key picks: “やっぱり俺は…” (I guess I…)
  • Episode 3 “Relationships Revealed”
    To enter Episode 4 “I'm Sorry” / “Kotonoha Broken” / “No More Hesitation”…03-SA: Need Sekai > Kotonoha (at this point Kotonoha 13 : Sekai 34); otherwise you enter Episode 4 “A Real Couple” / “Setsuna”03-KA
  • Episode 4 “No More Hesitation”
    To enter Episode 5 “Back to the Beginning” / “The One Hikari Loves” / “Transfer”04-SB: Need Sekai > Kotonoha (at this point Kotonoha 13 : Sekai 64); otherwise you enter Episode 4 “Waiting in Vain”03-S0
    Key picks: don't choose
  • Episode 5 “Transfer”
    To enter Final Episode No.19 Goodbye, Sekai / No.20 Setsuna's Feelings05-SD: Need Sekai > Kotonoha (at this point Kotonoha 28 : Sekai 64); otherwise you get the options “俺も、言葉が好きだ！”（I love Kotonoha too!）
  • Finally: Final episode: Sekai > 46 and don't pick 「いられるよ」
