『School Days REMASTERED』（スクールデイズ リマスター版）の全エンディング攻略です。

ネットで見つかるスクールデイズの攻略は、多くが HQ 版やそれ以前のバージョン向けです。筆者はそれらを見ながらリマスター版をプレイしましたが、どうしても狙ったルートに入れませんでした。そこでゲームのプログラムを解析し、すべての好感度の数値とルート分岐の条件を取り出し、ゲーム本来の分岐処理で一つずつ再生して確認したうえで、この全エンディング攻略をまとめました。22 個のエンディングそれぞれの選択肢、各選択肢による世界・言葉の好感度の変化、各分岐の判定条件、そして全エンディングを順に回収するためのセーブ手順を載せています。

間違いを見つけたら、ページ下部の X か GitHub からご連絡ください。

ゲームを購入：日本語版（オーバーフロー公式） · 英語・中国語版（JAST USA）
